# ADR-008: 自然语言日程输入采用本地确定性规则引擎

状态：已接受（2026-11-02）

## 背景

MVP 需要降低创建日程的输入成本，但历史蓝图明确不做云端日程 AI 分析。自然语言入口如果直接自动写入系统日历，会放大误建、误删时间以及隐私风险。

## 决策

1. v1 使用本地确定性中文规则，不接入云端模型或第三方 NLP 服务。
2. 解析器放入独立 `NaturalInput` Swift Package，只依赖 Foundation；中文规则表使用 JSON 资源，符合 ADR-007。
3. 解析结果永远进入既有新建日程表单，由用户确认后才写入 EventKit。
4. 解析器只产出“当前可解释”的日期、时间、重复、地点、备注和标题；不能解释的内容进入表单让用户补齐，不猜测保存。
5. 解析器接收外部 `Date` 作为参考时间，避免测试和跨日使用依赖真实时钟。

## 影响

- 用户输入成本低、可离线、结果稳定，也便于未来迁移到 Android/KMP。
- v1 无法覆盖开放语言表达；必须把未识别内容留在标题或警告中，让表单兜底。
- 后续若引入模型解释器，只能作为 `NaturalInputParser` 后备策略，不能绕过表单确认。
