# 月视图交互与周起始日 v1

状态：已实现代码基线；待模拟器 / 真机验收（2026-11-02）  
关联设计：[设计系统](design-system.md) · [多日历管理](calendar-management.md)

## 1. 目标

- 月视图支持左右滑动翻月。
- 用户可选择周一起始或周日起始。
- 周起始日设置立即影响星期表头、前置空格和月格分布。
- 设置写入本地 `UserDefaults`。

## 2. 非目标 v1

- 不做日 / 周 / 年视图。
- 不做双指缩放切换视图。
- 不做拖拽移动日程。
- 不做翻页 3D / 弹性动画。
- 不把周起始日同步到 CloudKit。

## 3. 手势

| 手势 | 行为 |
|---|---|
| 向左滑动 | 下一月 |
| 向右滑动 | 上一月 |
| 最小距离 | 56pt |
| 水平 / 垂直比例 | 水平距离至少为垂直距离的 1.5 倍 |

现有左右按钮保留，作为无障碍和明确入口。

## 4. 周起始日

| 设置 | firstWeekday | 表头 |
|---|---:|---|
| 周一起始 | 2 | 一 二 三 四 五 六 日 |
| 周日起始 | 1 | 日 一 二 三 四 五 六 |

默认值：周一起始。  
存储 key：`month.week.start.day`。  
值：`monday` / `sunday`。

## 5. 设置入口

设置页新增“周起始日”，使用 segmented Picker：

```text
周一 | 周日
```

修改后月视图立即刷新。
