# 日历视图矩阵与导航设计 v1

状态：v1.3 简化为月 / 年 / 议程，移除周期箭头（2026-11-05；GUI / 真机人工验收按当前决策暂跳过）
架构依据：[ADR-001](../architecture/adr/ADR-001-eventkit-as-source-of-truth.md)  
关联设计：[月视图交互](month-interaction.md) · [设计系统](design-system.md)

## 1. 目标

月视图是主工作台；点击任一天直接打开日详情 sheet。独立日视图和周视图已移除，避免重复入口。保留年视图与议程视图：

- 月视图
- 年视图
- 议程视图

共享同一个选中日期、可见月份、日历筛选和 EventKit 数据流。

## 2. 非目标 v1

- 不做自定义视图。
- 不做拖拽移动日程。
- 不做双指缩放。
- 不做跨视图多选。

## 3. 导航结构

顶部使用自定义胶囊分段控件，顺序固定为：

```text
月 | 年 | 议程
```

默认 `月`，持久化 key：

```text
calendar.view.mode
```

```swift
enum CalendarViewMode: String, CaseIterable {
    case month, week, day, agenda, year
}

struct CalendarNavigationState {
    var mode: CalendarViewMode
    var selectedDate: Date
    var visibleMonth: Date
}
```

切换视图不改 `selectedDate`；`visibleMonth` 由 `selectedDate` 推导。

[顶部不再提供左右箭头；翻页只使用滑动手势。锚点控件保持一致：]

```text
        yyyy年M月d日                          [今天] [跳转日期]
```

- 月视图左右滑切换上月 / 下月；点击任一天打开日详情 sheet。
- 年视图左右滑切换前一年 / 后一年。
- 议程视图左右滑切换上一个 / 下一个所选窗口。
- 中间锚点按钮点击后打开日期跳转层；年视图也必须复用同一控件，不得在内容区重复放置另一套年份箭头。
- `今天` 把 `selectedDate` 重置为当前时刻，并同步 `visibleMonth`；议程重新从今天开始。
- 年视图的年份切换由全局 `‹ / ›` 完成内容区只保留 12 个月矩阵和横滑手势。
- 日期跳转层允许直接选择 1900–2100 年、月、日三列；确认后共享给全部视图。

## 4. 各视图

### 月视图

继续使用现有月格、农历、休班、日程圆点、滑动翻月。选中日期打开日详情。
- 周末数字 / 农历使用朱砂色，日期格使用淡朱砂底。
- 法定休息日叠加淡朱砂底与官方 `休` 角标；估算数据显示 `休估`。
- 法定调休补班日叠加淡灰底与官方 `班` 角标；估算数据显示 `班估`。
- 星期表头中的周末文字使用朱砂色。

### 年视图

- 显示 12 个迷你月。
- 迷你月只显示日期、今日圆标、法定休/班角标、有日程小点。
- 点击迷你月切换到对应月视图。
- 不在年视图直接展示事件标题。
- 年份切换由全局 `‹ / ›` 完成；内容区左右横滑切换年份，纵向滚动浏览 12 个月。

### 议程视图

- 默认从今天开始，加载未来 30 天。
- 可切换未来 30 / 60 / 90 天。
- 按日期分组，空日期折叠为一行“无日程”。
- 单次最多渲染 500 个事件，超过时显示“加载更多”。


## 5. 数据加载

| 视图 | 加载区间 |
|---|---|
| 月 | 当前自然月 |
| 议程 | 今天 + 用户选择窗口 |
| 年 | 锚点年份的 12 个自然月分批区间 |

EventKit 请求失败时显示“无法读取系统日历”，不清空当前视图。

## 6. 手势

| 视图 | 手势 |
|---|---|
| 月 | 左右滑切换上一页 / 下一页 |
| 议程 | 上下滚动 |
| 议程 | 左右滑切换上一个 / 下一个窗口 |
| 年 | 左右滑切换年份；上下滚动 |

手势阈值沿用月视图：横向 >=56pt，且横向 >= 纵向 * 1.5。

## 7. 错误与边界

| 场景 | 行为 |
|---|---|
| 无日历权限 | 显示授权入口，保留农历 / 节假日 |
| 年视图区间过大 | 分 12 次加载，不合并成一个超大 predicate |
| 议程无数据 | 显示空态 |
| 跨天事件 | 在每天首行重复展示 |
| 隐藏日历 | 所有视图统一过滤 |
| 切换周起始日 | 周 / 年迷你月立即重排 |
| 跳转日期早于 EventKit 可读范围 | 农历 / 节假日仍展示，事件列表显示空态或授权错误 |
| 日期跳转年 / 月 / 日非法组合 | 天数按目标年月自动收敛，例如 2 月 30 日收敛为 2 月 28/29 日 |
| 年视图切换年份 | 先更新 `visibleMonth`，12 个自然月继续分批加载 |

## 9. 当前落地说明

- 新增 `CalendarScreen` 作为日历 Tab 入口，顶部使用自定义胶囊分段控件切换三种视图。
- 月视图保留原有能力，点击任一天打开详情 sheet，并把 `visibleMonth` / `selectedDate` 提升为共享状态。
- 独立日视图和周视图已从导航与代码中移除。
- 日视图包含黄历面板占位入口，完整面板由 D-160 接管。
- 议程视图支持 30 / 60 / 90 天，按日期分组，单次最多渲染 500 条并提供“加载更多”。
- 年视图显示 12 个迷你月，包含今日、休 / 班和事件点；点击月份回月视图。
- 年视图按 12 个自然月分批请求 EventKit，再合并去重展示。
- 月 / 年 / 议程均使用滑动手势翻页；全局导航条只保留锚点、今天和日期跳转。
