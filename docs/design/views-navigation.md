# 日历视图矩阵与导航设计 v1

状态：代码已接入（2026-11-04；GUI / 真机人工验收按当前决策暂跳过）  
架构依据：[ADR-001](../architecture/adr/ADR-001-eventkit-as-source-of-truth.md)  
关联设计：[月视图交互](month-interaction.md) · [设计系统](design-system.md)

## 1. 目标

在保留月视图为默认入口的前提下，补齐基础视图：

- 议程视图
- 日视图
- 周视图
- 年视图

共享同一个选中日期、可见月份、日历筛选和 EventKit 数据流。

## 2. 非目标 v1

- 不做自定义视图。
- 不做拖拽移动日程。
- 不做双指缩放。
- 不做跨视图多选。

## 3. 导航结构

顶部使用分段控件：

```text
月 | 周 | 日 | 议程 | 年
```

默认 `月`，持久化 key：

```text
calendar.view.mode
```

```swift
enum CalendarViewMode: String, CaseIterable {
    case month, week, day, agenda, year
}

struct CalendarNavigationState {
    var mode: CalendarViewMode
    var selectedDate: Date
    var visibleMonth: Date
}
```

切换视图不改 `selectedDate`；`visibleMonth` 由 `selectedDate` 推导。

## 4. 各视图

### 月视图

继续使用现有月格、农历、休班、日程圆点、滑动翻月。选中日期打开日详情。

### 周视图

- 显示当前周 7 天。
- 每列显示日期、农历缩写、事件数量或最多 3 个事件标题。
- 横向滑动切换上一周 / 下一周。
- 点击某天切换到日视图。

### 日视图

复用现有日详情内容，升级为全屏页面：

1. 顶部日期、农历、干支、节假日状态。
2. 日程列表，支持新建。
3. 里程碑横幅。
4. 下方显示黄历面板入口。

### 议程视图

- 默认从今天开始，加载未来 30 天。
- 可切换未来 30 / 60 / 90 天。
- 按日期分组，空日期折叠为一行“无日程”。
- 单次最多渲染 500 个事件，超过时显示“加载更多”。

### 年视图

- 显示 12 个迷你月。
- 迷你月只显示日期、今日圆标、法定休/班角标、有日程小点。
- 点击迷你月切换到对应月视图。
- 不在年视图直接展示事件标题。

## 5. 数据加载

| 视图 | 加载区间 |
|---|---|
| 月 | 当前自然月 |
| 周 | 当前自然周 |
| 日 | 当天 |
| 议程 | 今天 + 用户选择窗口 |
| 年 | 12 个自然月分批区间 |

EventKit 请求失败时显示“无法读取系统日历”，不清空当前视图。

## 6. 手势

| 视图 | 手势 |
|---|---|
| 月 / 周 | 左右滑切换上一页 / 下一页 |
| 日 | 左右滑切换前一天 / 后一天 |
| 议程 | 上下滚动 |
| 年 | 上下滚动 |

手势阈值沿用月视图：横向 >=56pt，且横向 >= 纵向 * 1.5。

## 7. 错误与边界

| 场景 | 行为 |
|---|---|
| 无日历权限 | 显示授权入口，保留农历 / 节假日 |
| 年视图区间过大 | 分 12 次加载，不合并成一个超大 predicate |
| 议程无数据 | 显示空态 |
| 跨天事件 | 在每天首行重复展示 |
| 隐藏日历 | 所有视图统一过滤 |
| 切换周起始日 | 周 / 年迷你月立即重排 |

## 9. 当前落地说明

- 新增 `CalendarScreen` 作为日历 Tab 入口，顶部使用分段控件切换五种视图。
- 月视图保留原有能力，并把 `visibleMonth` / `selectedDate` 提升为共享状态。
- 周视图显示 7 天、农历、最多 3 个事件标题和超额数量，横向滑动切换周。
- 日视图提供前后一天、农历 / 干支 / 节假日、里程碑、日程列表与新建入口。
- 日视图包含黄历面板占位入口，完整面板由 D-160 接管。
- 议程视图支持 30 / 60 / 90 天，按日期分组，单次最多渲染 500 条并提供“加载更多”。
- 年视图显示 12 个迷你月，包含今日、休 / 班和事件点；点击月份回月视图。
- 年视图按 12 个自然月分批请求 EventKit，再合并去重展示。
