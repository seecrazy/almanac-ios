## 2. MVP 内最高优先缺口

按“补上后产品才像完整日历”排序：

1. **多日历显示 / 隐藏 / 颜色**：月格日程点应使用日历分类色；日详情可按日历筛选。
2. **翻月手势与周起始日**：当前只有按钮翻月。
3. **官方节假日数据管道**：2026 sample 不能代表产品承诺。
4. **事件搜索**：v1 可先 EventKit predicate / 内存过滤，引入 SQLite 后升级 FTS。
5. **里程碑数据模型**：把静态倒计时样卡变成真实 `Milestone` 列表。
6. **重复规则完整编辑**：自定义周几、COUNT 结束、系列操作和规则预览。
