## 2. MVP 内最高优先缺口

按“补上后产品才像完整日历”排序：

1. **官方节假日数据替换**：管道已接入，但 2026/2027 仍是 sample，不能代表产品承诺。
2. **搜索升级**：v2 日期 / 日历筛选与最近搜索已接入；SQLite FTS 与完整本地索引未实现。
3. **中国日历差异化**：黄历面板与生日 / 纪念日已接入；二十四节气未实现。
4. **里程碑平台升级**：Live Activity、SQLite / GRDB、模板与颜色自定义。
