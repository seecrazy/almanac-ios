## 2. MVP 内最高优先缺口

按“补上后产品才像完整日历”排序：

1. **搜索升级**：SQLite FTS5 可重建索引已接入；增量更新、拼音 / 模糊纠错、复杂查询与故障注入验收未实现。
2. **中国日历差异化**：黄历面板、生日 / 纪念日、二十四节气与农历节日已接入；地方性 / 少数民族节日未实现。
3. **里程碑平台升级**：Live Activity、SQLite / GRDB、模板与颜色自定义。
4. **2027 官方节假日数据替换**：当前只能保留显式 sample，等待官方通知。
