## 2. MVP 内最高优先缺口

按“补上后产品才像完整日历”排序：

1. **官方节假日数据管道**：2026 sample 不能代表产品承诺。
2. **重复规则完整编辑**：自定义周几、COUNT 结束、系列操作和规则预览。
3. **议程 / 日 / 周 / 年视图**：补齐基础视图矩阵。
4. **搜索升级**：日期 / 日历筛选、SQLite FTS、最近搜索。
5. **里程碑升级**：提醒、SQLite / GRDB、Widget、Live Activity。
