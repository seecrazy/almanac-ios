# 宜历设计系统 v0.1

状态：已建立基线（2026-11-01）  
代码来源：`App/Almanac/Theme.swift`  
适用范围：iOS App Shell、月视图、日详情、事件创建表单

## 1. 设计原则

1. **纸感时间轴**：界面像一本安静的台历，信息分层清晰，不做娱乐化视觉。
2. **农历与公历同级呈现**：农历不是装饰小彩蛋，而是日期的第二语义。
3. **状态语义优先**：法定休、调休补班、今日、日程占用使用固定语义色，不用随机彩色。
4. **系统日历是事实**：日程数据来自 EventKit，UI 不制造“看起来像已同步”的假状态。
5. **低输入成本**：创建日程只保留 MVP 必填项，后续自然语言输入必须能映射到同一表单模型。

## 2. 色彩 Token

所有颜色通过自定义 `Palette` 环境读取，不直接散落硬编码色值。

| Token | 语义 | Light | Dark |
|---|---|---|---|
| `background` | 全局纸感底色 | `#FAF8F5` | `#141310` |
| `card` | 卡片 / 表单容器 | `#FFFFFF` | `#1E1D1A` |
| `ink` | 主文本 | `#1C1B1A` | `#EDEAE4` |
| `secondary` | 次级文本、说明 | `#8A8782` | `#9B978E` |
| `separator` | 分割线 / 弱轮廓 | `#ECE9E4` | `#2A2925` |
| `holidayRed` | 法定休、节日、危险反馈 | `#C73E3A` | `#E06A5E` |
| `makeupGray` | 调休补班标记 | `#9A968F` | `#7A766E` |
| `solarGreen` | 节气 / 自然类语义 | `#3E7C6B` | `#6FA893` |
| `accent` | 今日、主按钮、日程强调 | `#B5893C` | `#D4A853` |

### 使用规则

- `holidayRed` 同时承担“法定休”和错误反馈，但在不同组件中必须由布局区分。
- `makeupGray` 只用于补班/受限状态，不用于普通 secondary 文本。
- `accent` 是品牌主行动色，不与节假日红混用。
- 深色模式不是简单反色：纸感底色转为墨感底色，卡片仍保持相对抬升。

## 3. 字体与层级

| 层级 | 用法 | 字体 |
|---|---|---|
| 页面标题 | “月历”“倒计时”“设置” | 28pt / semibold / serif |
| 日期大数字 | 月格日期、日详情日期 | 17–56pt，关键日期用 serif |
| 卡片标题 | “今日日程”、日程标题 | 15–17pt / medium |
| 辅助说明 | 农历、时间、权限说明 | 10–14pt |
| 角标 | 休 / 班 | 8pt / medium |

规则：

- 公历数字优先保证扫读性。
- 农历、干支使用较小字号，但不得低于 10pt。
- 不用颜色单独表达休/班状态，必须配合文字角标。

## 5. 核心组件状态

### 日期格

- 普通日：公历数字 + 农历小字。
- 今日：`accent` 圆标 + 白色数字 + 白色日程点。
- 法定休：农历小字使用 `holidayRed`，右上角“休”。
- 调休补班：数字和农历使用 `makeupGray`，右上角“班”。
- 有日程：日期数字下方显示 `accent` 圆点；今日显示白点。

### 日详情

- 顶部展示公历大数字、完整日期、农历和干支。
- 法定休/补班以胶囊状态条显示。
- 日程列表按全天优先、开始时间次序排序。
- 空状态统一为“这一天暂无日程”，不暗示 App 数据异常。

### 新建日程

- 必填：标题；有时间段时结束时间必须晚于开始时间。
- 常用可选：全天、开始/结束、地点、备注。
- 保存目标：只列出 `allowsContentModifications == true` 的系统日历。
- 保存中禁用主按钮并显示进度。
- 错误就地显示，不吞掉 EventKit 的失败原因。

## 6. 反馈与权限文案

| 状态 | 文案方向 |
|---|---|
| 未请求权限 | “尚未请求日历权限”，提供明确授权按钮 |
| 授权成功 | 说明日程来自系统日历 |
| 拒绝权限 | 指向系统设置路径，不责备用户 |
| 无可写日历 | 明确说明无法保存，并提示检查系统日历 |
| EventKit 保存失败 | 保留系统错误原因，避免笼统“失败” |
